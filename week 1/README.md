# Mini E-Learning Platform

A simple e-learning dashboard built with HTML, CSS, and JavaScript.

## Features
- Course listing with progress tracking
- Detailed course views with lesson lists
- Progress visualization
- Course completion marking

## File Structure
- `index.html` - Main HTML file
- `styles/style.css` - All styling
- `js/courses.js` - Course data structure
- `js/utils.js` - Utility functions
- `js/app.js` - Main application logic

## Setup
1. Download all files
2. Open `index.html` in a web browser
3. No server required - runs directly in browser

## Usage
- Click on any course card to view details
- Use the back button to return to the course list
- Mark courses as completed when all lessons are done
